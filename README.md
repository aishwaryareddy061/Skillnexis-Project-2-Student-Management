# Student Management System

## 📌 Project Overview

The **Student Management System** is a Python-based mini project developed as part of my **Skillnexis Python Programming Internship – Week 2**.

The project allows users to manage student records using **Python and CSV file handling**.

## ✨ Features

* ➕ Add new student records
* 👀 View all student records
* 🔍 Search students using Roll Number
* 🗑️ Delete student records
* 💾 Store student data permanently in a CSV file
* ⚠️ Validate marks between 0 and 100
* 🛡️ Handle invalid inputs and missing files

## 🛠️ Technologies Used

* **Python 3**
* **CSV File Handling**
* **Functions**
* **Exception Handling**
* **CRUD Operations**

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open the project folder in VS Code or PowerShell.
3. Run the following command:

```bash
python student_management.py
```

4. Select an option from the menu:

```text
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit
```

## 📄 CSV Data

Student records are stored in `students.csv` with the following format:

```csv
Roll Number,Name,Marks
12,aish,85
```
